# 5W Investigation Note

> One of these per IOC or per timeline event. Keep ≤200 words.

- **Who** — actor IP / account / host; victim asset.
- **What** — technique (MITRE ATT&CK ID), tool, payload.
- **When** — UTC timestamp (with local offset noted).
- **Where** — affected asset(s), network segment, geography.
- **Why / How** — position in kill chain; how the technique was executed; what data or access was sought.

## Confidence
- **Level:** low / medium / high
- **Evidence cited:** <log line / hash / memory offset>
- **What would raise this:** <missing corroboration source>
